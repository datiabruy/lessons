ОСНОВНЫЕ ТЕГИ HTML

1.СТРУКТУРА Web-страницы
<html></html> Начало и конец страницы
<head></head> Описание страницы
<title></title> Имя страницы
<body></body> Определяет видимую часть страницы
2.АТРИБУТЫ ТЕЛА ДОКУМЕНТА Значение атрибутов
<body background="URL"> Фоновое изображение
<body bgcolor="#RRGGBB"> Цвет фона документа red, blue, #FF0000 и др.
<body text="#RRGGBB"> Цвет текста документа
<body link="#RRGGBB"> Устанавливает цвет гиперссылок
<body vlink="#RRGGBB"> Устанавливает цвет гиперссылок
<body alink="#RRGGBB"> Устанавливает цвет гиперссылок
3.ТЕГИ ДЛЯ ФОРМАТИРОВАНИЯ ТЕКСТА Значение атрибутов
<h?></h?> Создает заголовок
<h? align="*"></h?> Заголовок с выравниванием left, right, center
<p></p> Создает новый параграф
<p align="*"></p> Выравнивает параграф left, right, center, justify
<br> Вставляет перевод строки
<center></center> Выравнивание по центру
<div align="*"> Форматирование больших блоков текста left, right, center, justify
4.ТЕГИ ДЛЯ ФОРМАТИРОВАНИЯ ШРИФТА Значение атрибутов
<b></b> Жирный
<i></i> Курсив
<u></u> Подчёркнутый
<sup></sup> Верхний индекс - пример:a2
<sub></sub> Нижний индекс - пример:a2
<font size></font> Размер шрифта в пределах от 1 до 7
